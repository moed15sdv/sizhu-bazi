# 知命 · 四柱八字

一个部署在 GitHub Pages 的四柱八字网页：本地排盘、分享链接、五行与十神展示，并可按需调用 Kimi API 生成解读。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm test
npm run build
```

## 功能与口径

- 公历 1901—2099 年排盘；年柱以立春、月柱以节气为界。
- 晚子时可选“当日日柱”或“次日日柱”。
- 出生地仅作 AI 解读背景，当前不校正真太阳时。
- 分享链接使用 URL hash 保存 Base64URL 编码的出生信息；编码不等于加密。
- 五行条形图只统计四柱天干与地支，不含藏干，不直接用于判断旺衰。
- 排盘基于 `lunar-javascript`，在浏览器本地完成。

## Kimi API

默认模型为 `kimi-k2.6`，接口为 `https://api.moonshot.cn/v1/chat/completions`。在页面中填写自己的 Moonshot API Key 后才会发起请求。

**安全说明：** GitHub Pages 是纯静态托管，无法安全保管网站所有者的服务端密钥。因此本站采用用户自带密钥（BYOK），密钥仅保留在当前页面的内存中，不写入 localStorage、分享链接或源代码，并在成功请求后清空输入框。不要在公用设备上输入密钥。

如要让所有访问者免密钥使用，应另行部署受保护的服务端代理，在服务端保管 API Key，并加入鉴权、限流与用量控制；不要把个人密钥写进前端代码。
